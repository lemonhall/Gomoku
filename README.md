# 3D 五子棋 (Gomoku 3D)

这是一个基于 Web 技术的 3D 五子棋游戏，使用 Three.js 库构建。

## 功能特点

*   **3D 视觉体验**：沉浸式的 3D 棋盘和棋子效果。
*   **多种游戏模式**：
    *   **人机对战 (PvE)**：挑战内置的 AI 对手。
    *   **双人对战 (PvP)**：与朋友在同一台设备上对弈。
*   **交互友好**：支持鼠标悬停预览落子位置，视角自由旋转缩放。
*   **响应式设计**：适配不同屏幕尺寸。

## AI 算法详解

本项目实现了一个基于**贪心策略**和**启发式评分**的五子棋 AI。虽然没有使用 Minimax 或 Alpha-Beta 剪枝等高级搜索算法，但对于初级到中级玩家来说，它已经具备了一定的挑战性。

### 核心逻辑

AI 的决策过程主要包含以下步骤：

1.  **遍历空位**：扫描棋盘上所有尚未落子的位置。
2.  **双重评估**：对于每一个空位，进行两次评分：
    *   **进攻评分**：假设 AI 在该位置落子，计算对自己形成的优势。
    *   **防守评分**：假设玩家在该位置落子，计算对玩家形成的优势（即 AI 需要阻止的威胁）。
3.  **综合打分**：`总分 = 进攻分 + 防守分`。这使得 AI 既会寻找获胜机会，也会积极封堵玩家的进攻。
4.  **择优落子**：选择总分最高的位置。如果存在多个最高分位置，则从中随机选择一个，增加走法的不确定性。

### 评分模型

评分函数 `evaluatePoint` 会检查四个方向（横、竖、左斜、右斜），根据连续棋子的数量和两端是否被封堵来赋予不同的分值：

*   **连五 (Win)**：100,000+ 分。立即获胜或阻止对方立即获胜。
*   **活四 (Live 4)**：50,000 分。两端都为空，下一步必胜。
*   **冲四 (Dead 4)** / **活三 (Live 3)**：10,000 分。具有较强威胁。
*   **活二 (Live 2)**：500 分。
*   **位置加权**：为了避免 AI 在开局时过于分散，算法还引入了位置加权，越靠近天元（棋盘中心）的位置会有微小的额外加分。

这种基于棋型的静态评估方法，能够快速识别出关键着法，实现快速响应。

## 如何运行

本项目是一个纯静态网页应用，但由于使用了 ES Modules，需要通过本地服务器运行。

### 方法 1: 使用 Python (推荐)

如果你安装了 Python，可以直接运行项目根目录下的启动脚本：

```bash
python start_game.py
```

这将启动一个本地服务器（默认端口 8080）并自动在浏览器中打开游戏。

### 方法 2: 使用其他静态服务器

你可以使用任何你喜欢的静态文件服务器，例如 `http-server` (Node.js):

```bash
npx http-server .
```

或者 VS Code 的 "Live Server" 插件。

## 游戏规则

1.  黑棋先行。
2.  双方轮流在棋盘的空位上落子。
3.  先在横、竖、斜任意方向连成五子者获胜。
